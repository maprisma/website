Download & Install from GitHub

Every Maprisma app lives in the github.com/maprisma organization. Maprisma and the windowed apps (Settings, Theme, Launcher, Playground) come as a ready-to-run AppImage, manage the whole suite via Maprisma Settings, or install any repository directly with its local installer script.

1

AppImage or Release Archive

Maprisma, Maprisma Settings, Theme, Launcher and Playground have a portable x86_64 AppImage and a release archive on each app's GitHub Releases page. Check the SHA-256 checksum, make the AppImage executable and start it. For Maprisma the archive is recommended (background local LLM service). Panel applets, tray icons and the shell are installed from source (step 3). 

sha256sum -c Maprisma-Settings-*-x86_64.AppImage.sha256
chmod +x Maprisma-Settings-*-x86_64.AppImage
./Maprisma-Settings-*-x86_64.AppImage
2

Manage Everything in Maprisma Settings

Install Maprisma Settings once to install, update, and cleanly remove any Maprisma app — and place their panel applets or tray icons on COSMIC, KDE Plasma, and Hyprland. 

git clone https://github.com/maprisma/settings.git maprisma-settings
cd maprisma-settings
./tools/install-local
maprisma-settings
3

Clone & Install Individual Apps

Every Rust panel applet and Flutter app includes an idempotent installer (./install.sh or ./tools/install-local) that installs cleanly into ~/.local without touching system files. 

git clone https://github.com/maprisma/wlan-monitor.git
cd wlan-monitor
./install.sh
